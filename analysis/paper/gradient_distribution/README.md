# Gradient-distribution figure

Regenerate from the repository root:

```bash
python scripts/plot_gradient_distribution.py
```

The figure compares MSE, Flow, and HT using the same quantity in all four
panels: the fraction of total squared output-gradient mass in a residual bin,
divided by the fraction of samples in that bin. A value of one is proportional
allocation. Values above one mean that the objective amplifies that residual
range relative to its frequency in the data.

## Numerical sources

- Panels (a,b): converged-checkpoint tables E8a (GR1) and E8b-corrected
  (pi0.5) in `analysis/paper/vla_results_table.md`. GR1: 320 samples, residual
  from the deployed 4-step Euler sample (Gaussian start), 8 (t, x0) draws with
  t = (1-u)*0.999, u ~ Beta(1.5, 1), x0 ~ N(0, I); all 29 channels. pi0.5:
  600 samples, residual from the deployed stochastic 10-step sampler, 8 draws
  with t = 0.999*Beta(1.5, 1) + 0.001 and x0 ~ N(0, I); all 7 channels. The
  original pi0.5 probe (E8b) had x0 forced to zero in the loss draws and a
  zero-start residual; it was rerun on 2026-09-06 (`pi05/resid_flow_pi05_v2.py`
  on PFS). The pi0.5 >4x bin holds one sample and is not drawn.
- Panels (c,d): `robomimic_gradient_probes.json`, generated by
  `scripts/probe_robomimic_gradient_distribution.py` from converged Flow
  checkpoints. Each task uses 1,024 training windows, eight Flow noise--time
  draws, nine inference steps, and continuous action channels only. HT uses
  $\nu=2d$ and the same pooled scale used to normalize residuals.

Tool-Hang and Square-PH are displayed because their converged Flow residuals
span all five plotted ranges, making tail-gradient behavior directly visible.
Transport-MH and Transport-PH were probed with the same protocol and are
retained in the JSON file. Their chunk-level RMS falls almost entirely between
$0.5\times$ and $2\times$ pooled RMS, so they do not diagnose tail allocation
at this aggregation level.

Claim supported: MSE increasingly over-allocates gradient to large-residual
samples, whereas Flow and HT keep the rarest residual bins close to
proportional. The figure does not assert that every large residual is noise or
identify the cause of any individual residual.
